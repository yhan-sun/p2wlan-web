Windows

  1. 下载 {{asset.windows-x64.name}}。
  2. 核对下载页展示的 SHA-256。
  3. 运行安装程序；创建虚拟网卡或修改路由时，系统可能请求管理员权限。
  4. 如果 Windows 安全提示阻止安装，先核对发布来源和摘要，再决定是否继续。

不要为了排障长期关闭 Defender、防火墙或驱动签名保护。需要放行时，应限定到 P2WLAN 程序和必要网络范围。

macOS

  1. Apple Silicon 下载 arm64 DMG；Intel Mac 下载 x64 DMG。
  2. 打开 DMG，将应用拖入 Applications。
  3. 首次启动和创建 utun 接口时，按系统提示授权。

客户端若触发 Gatekeeper 提示，应先验证 digest。不要使用不明来源的“去签名”或二次打包版本。

Linux GUI

x86_64 桌面环境可以使用 Flutter tarball。解压后从目录启动，并确保系统具备创建 TUN 接口所需权限。

bash
mkdir -p p2wlan-linux-x64
tar -xzf {{asset.linux-gui-x64.name}} -C p2wlan-linux-x64
cd p2wlan-linux-x64
./p2wlan

Linux CLI

服务器更推荐 CLI + daemon。可以手工下载对应架构的 tarball，或先审阅官方安装脚本再执行：

bash
curl -fsSL https://raw.githubusercontent.com/yhan-sun/p2wlan/{{release.tag}}/scripts/install-linux-cli.sh -o /tmp/p2wlan-install.sh
less /tmp/p2wlan-install.sh
sudo sh /tmp/p2wlan-install.sh --version {{release.tag}}
关于安装脚本
脚本便于更新，但执行远程脚本前仍应先审阅。需要更严格的供应链控制时，请手工下载 tarball、核对 SHA-256，再将二进制安装到受控目录。

Android

当前提供 arm64 APK，需要启用允许该来源安装应用。首次启动虚拟网络时，Android 会显示 VPN 权限对话框。部分系统的省电策略会限制后台网络，请为 P2WLAN 关闭不必要的后台冻结，而不是关闭整个系统安全能力。

OpenWrt 路由器

OpenWrt 24.10 使用 IPK，25.12 使用 APK。支持 x86_64 与 ARM64 的 generic、Cortex-A53、A72、A76 包架构；手动下载时以固件的 DISTRIB_ARCH 为准。这里的 APK 是 OpenWrt 原生包。

在路由器上以 root 运行下面的固定版本安装器。脚本读取固件版本与包架构，核对同一 tag 的发布清单 SHA-256，再由原生包管理器安装：

sh
VERSION={{release.tag}}
wget -O /tmp/p2wlan-install.sh "https://raw.githubusercontent.com/yhan-sun/p2wlan/$VERSION/scripts/install-openwrt.sh"
sh /tmp/p2wlan-install.sh --version "$VERSION"

p2wlan config set control https://control.example.com
p2wlan login -u user@example.com
p2wlan up
p2wlan status

将示例 Control 地址与账号替换为自己的服务和账号。安装前检查闪存及 /tmp 内存余量；kmod-tun 必须来自匹配当前内核的固件软件源。32 位 ARM、MIPS、厂商私有固件与 snapshot 不在当前支持范围。

当前支持路由器本机加入虚拟网络，不自动发布 LAN 子网，不提供 LuCI。默认网络由 procd 管理；独立房间实例重启后需重新连接。升级时先执行 p2wlan down，重新运行目标版本的原生安装器，再执行 p2wlan up；普通 Linux glibc tarball 与 p2wlan update 不适用于 OpenWrt。

服务管理、配置备份与防火墙设置见 主仓库 OpenWrt 安装与服务指南。

iOS

Release 中的 IPA 是未签名实验构建，不能像 App Store 应用一样直接安装。需要使用自己的开发者签名和受支持的安装流程。普通用户应将 iOS 支持视为实验性能力。

升级

桌面与移动端从新 Release 覆盖安装。Linux CLI 支持：

bash
p2wlan update --dry-run
p2wlan update
# 安装指定版本
p2wlan update --version {{release.tag}}

升级前保存配置路径：p2wlan config path。自托管服务升级前应备份 SQLite 数据库和环境配置。
